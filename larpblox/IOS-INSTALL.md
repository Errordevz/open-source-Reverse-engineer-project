LarpBlox iPhone setup

1. Open the deployed LarpBlox URL in Safari (not an in-app browser).
2. Tap Share.
3. Tap Add to Home Screen.
4. Name it LarpBlox and tap Add.

This is the recommended iOS install path. The app itself is a normal website/PWA-style page; no bookmarklet is needed.

Optional Safari bookmarklet:
After deployment, create a Safari bookmark to the deployed LarpBlox URL. Edit that bookmark's URL and replace it with the javascript: URL supplied in bookmarklet.js (replace APP_URL with the deployed URL first). iOS Safari may require creating a normal bookmark first and then editing its URL. Bookmarklets generally do not run in Chrome on iOS.
