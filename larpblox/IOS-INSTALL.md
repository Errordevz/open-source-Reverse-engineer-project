# iPhone install and Backstage

1. Open the LarpBlox deployment in Safari.
2. Tap Share → Add to Home Screen → Add.
3. Launch from the new Home Screen icon.
4. To edit the simulator, press and hold the very top edge of the screen for about one second. A charging strip fills and Backstage slides up.
5. Edits save automatically in this browser on this device.

Optional Safari bookmarklet:
Create a normal Safari bookmark, edit its URL, and replace the address with the javascript: URL in bookmarklet.js. iOS Safari may strip the javascript: prefix when pasted; if so, restore it before saving. The bookmarklet only opens the LarpBlox website; it does not inject code into Roblox pages.
